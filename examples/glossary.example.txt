# 领域术语表示例：编程语言 / 类型论 / 运行时
#
# This is the glossary used while developing this package, against a PL paper on
# effect and coeffect systems. It shows how far a domain glossary should go: the
# point is not to translate every word, but to pin down the vocabulary the paper
# keeps re-using, so one concept never appears under two different Chinese words.
#
#   run.py paper.pdf --glossary examples/glossary.example.txt
#
# This file is MERGED over the built-in scripts/glossary.txt, which carries the
# structural terms (theorem, figure, section, ...). Merging means you never have
# to repeat those, and you cannot accidentally drop them by passing a glossary
# that does not mention them.
